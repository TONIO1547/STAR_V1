# CAO de la V1

Tous les fichiers sont au format **OBJ** (chaque `.obj` est accompagné de son `.mtl`
qui décrit les matériaux). Les trois plus gros fichiers sont compressés en `.zip`
pour respecter les limites de GitHub : il suffit de les décompresser.

| Fichier | Contenu |
|---|---|
| `obj/assemblage_complet_v1.zip` | Assemblage complet du robot |
| `obj/chassis.zip` | Châssis |
| `obj/chassis_avec_suspension.zip` | Châssis avec suspension |
| `obj/chenille.obj` | Chenille |
| `obj/roue_arriere_motrice.obj` | Roue arrière (sur l'arbre moteur) |
| `obj/roue_avant.obj` | Roue avant |
| `obj/galet_lateral.obj` | Galet latéral |
| `obj/arbre_suspension_droit.obj` / `_gauche.obj` | Arbres de suspension |
| `obj/tourelle_canon.obj` | Tourelle canon (suivi) |
| `obj/base_tourelle_canon.obj` | Base de la tourelle canon |
| `obj/tourelle_guet.obj` | Tourelle de guet (balayage) |
| `obj/bras_tourelle_guet.obj` | Bras de la tourelle de guet |
| `modele_v1.glb` | Assemblage complet en version légère (glTF compressé) |

Ces fichiers sont protégés : voir [LICENSE](../LICENSE).
