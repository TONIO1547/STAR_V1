# CAO de la V1

Tous les fichiers sont au format **OBJ** (chaque `.obj` est accompagné de son `.mtl`
qui décrit les matériaux). Les trois plus gros fichiers sont compressés en `.zip`
pour respecter les limites de GitHub : il suffit de les décompresser.

| Fichier | Contenu |
|---|---|
| `obj/montage_fin_w_chaine.zip` | Assemblage complet du robot |
| `obj/base_immobile.zip` | Base |
| `obj/base_immobile_w_suspension.zip` | Base avec suspension |
| `obj/chaine_assemblage.obj` | Chaîne (chenille) |
| `obj/roue_arriere.obj` | Roue arrière |
| `obj/roue_avant.obj` | Roue avant |
| `obj/roue_cote.obj` | Roue de côté |
| `obj/arbre_susp_droite.obj` / `arbre_susp_gauche.obj` | Arbres de suspension |
| `obj/tourelle_canon.obj` | Tourelle canon |
| `obj/base_tourelle_canon.obj` | Base de la tourelle canon |
| `obj/tourelle_guet_360.obj` | Tourelle de guet |
| `obj/bras_tourelle_guet.obj` | Bras de la tourelle de guet |
| `modele_v1.glb` | Assemblage complet en version légère (glTF compressé) |
